# Changelog

## 0.1.0 - Initial development

- Added automatic styling for known Valheim 1.0.16 master sign labels.
- Added role prefixes for ambiguous labels: `P:`, `H:`, `T:`, and `S:`.
- Added `RAW:` bypass support.
- Preserved existing manual rich text by default.
- Added the extracted 1.0.16 master style catalog.
- Added automated validation for sign length, formatting rules, and catalog invariants.
